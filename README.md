# BlazesRus Licenses
Canonical source for BlazesRus software licenses and license specifications.

This repository contains the official license texts, version history,
release notes, and supporting documentation for the BlazesRus license family.

## Current Licenses

### Public License Family

- BBPL — BlazesRus Boundary Preserving License

  BBPL is a boundary-preserving permissive license.

  Similar category to:
  - MIT
  - Apache 2.0

  Key characteristics:
  - No source availability requirement
  - Commercial use allowed
  - Proprietary use allowed
  - Preservation of attribution
  - Preservation of rights
  - Preservation of boundaries
  - Preservation of origin
  - Preservation of notices

- BBPL-C — BlazesRus Boundary Preserving License - Copyleft

  BBPL-C extends BBPL through code-lineage source preservation.

  Key characteristics:
  - Source availability required for BBPL-C code lineage
  - Independent software remains independent
  - Source obligations follow code lineage
  - License obligations remain within defined boundaries
  - No propagation through linking, loading, plugin usage, framework usage, aggregation, interoperability, configuration, or software proximity alone

### Proprietary Mathematics License Family

- BPML — BlazesRus Proprietary Mathematics License

  BPML is intended for proprietary mathematical technologies,
  numerical systems, formulas, models, algorithms, and related
  intellectual property.

- BPCML — BlazesRus Proprietary Community Mathematics License

  BPCML is intended for community-facing mathematical extensions
  and related technologies while preserving the mathematics-family
  licensing model.

  Unlike BPML, BPCML is intended to support broader community
  participation while preserving attribution, ownership, and
  mathematical intellectual-property protections.

## Canonical Publication
Until superseded by an official publication website, the licenses
published in this repository are considered the canonical GitHub
versions of the BlazesRus license family.

## BBPL Family Principles
The BBPL family is built around:
- Preservation of Attribution
- Preservation of Rights
- Preservation of Boundaries
- Preservation of Origin
- Preservation of Notices

BBPL-C additionally provides:
- Preservation of Code Lineage

Core Principle:
> Fairness follows code lineage, not ecosystem proximity.
